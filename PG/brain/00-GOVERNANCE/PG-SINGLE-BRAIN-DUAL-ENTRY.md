# PG 单脑双入口声明

## 当前决定

PG 只保留一个 brain 真源：

`~/SYOO1-PG/brain`

本 brain 是 PG 独立主脑，不属于 Core-v2，不属于旧 58789，不继承旧运行壳。

## 单脑双入口

PG brain 有两个入口：

1. OpenClaw PG 入口  
   - 用于对话、判断、审核、工具调用、任务执行、监管协作。
   - 只能作为入口和运行壳。
   - 不得把前层 session / workspace / runtime 当作长期主脑。

2. Obsidian PG 入口  
   - 用于后层管理、可视化、搜索、整理、关联、生长。
   - 与 OpenClaw PG 入口共用同一个 PG brain。
   - 不是另一套脑，不做双脑同步。

## 与旧 58789 的关系

旧 58789 视作废弃旧壳。

PG 新系统不得继承旧 58789 的：

- runtime
- workspace
- session
- token
- logs
- 前层状态
- OpenClaw 4.14 壳配置

旧 58789 不作为回退体，不作为来源，不作为参考。

## 与 Core-v2 的关系

Core-v2 是执行脑 / 日常协作脑。  
PG 是监管脑 / 审核脑 / 备用判断脑。  

二者独立运行，互不混用：

- 不混用 brain
- 不混用 runtime
- 不混用 workspace
- 不混用 session
- 不混用 token
- 不混用前层状态
- 不混用拼测器实例

## 新03关系

新03是通用工艺母体、审核标准和判断方法。  
PG 可以使用新03思想和标准，但需要 PG 专属审核项。

PG03 是 PG 专属包装层，不是另一个新03母体。

## 当前目标

把 `~/SYOO1-PG/brain` 改造成：

- PG 独立 brain
- 新03思想分层
- Obsidian 后层管理
- OpenClaw PG 前台入口
- 单脑双入口系统
