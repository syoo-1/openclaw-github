# PG brain 分层索引

## 总原则

PG brain 是 PG 的唯一主脑真源：

`~/SYOO1-PG/brain`

OpenClaw PG 和 Obsidian PG 只是两个入口。  
二者共用同一个 PG brain，不形成双脑，不做双脑同步。

## 分层结构

### 00-GOVERNANCE

用途：PG 的最高规则、边界、审核原则、单脑双入口声明。

当前重点文件：

- `PG-SINGLE-BRAIN-DUAL-ENTRY.md`
- `PG-BRAIN-LAYER-INDEX.md`

### 01-IDENTITY

用途：PG 身份、老林身份、PG 与 Core-v2 的关系、职责边界。

应回答的问题：

- 你是谁？
- 我是谁？
- 你和 Core-v2 什么关系？
- 你的职责是什么？

### 02-MAINLINE

用途：PG 当前现实、当前阶段、当前主线。

当前重点文件：

- `PG-CURRENT.md`

### 03-LONGTERM

用途：PG 长期记忆、长期判断、长期经验沉淀。

原则：

- 只放已经确认、可长期使用的内容。
- 不放临时 session。
- 不放旧 58789 前层状态。

### 04-COMPILED

用途：给前台入口快速读取的压缩入口、总纲、前台说明。

当前重点文件：

- `PG-FRONTEND-ENTRY.md`

### 05-RAW

用途：原始材料、未整理材料。

原则：

- 可以保存材料。
- 不等于正式结论。
- 不直接作为 PG 当前现实。

### 06-ADAPTERS

用途：PG 与外部工具、入口、壳适配器、Obsidian、OpenClaw 的连接说明。

### 07-GROWTH

用途：新想法、新候选、新生长内容。

原则：

- 可生长。
- 可整理。
- 未确认内容不得直接冒充正式长期记忆。

### 08-IMPORT-STAGING

用途：临时导入、待分拣、待确认、最近事项缓冲。

原则：

- 可暂存。
- 不长期居住。
- 重要内容后续再整理进入合适层。

### 99-DEFERRED

用途：暂缓、搁置、待以后判断的内容。

## 禁止

- 禁止从旧 58789 继承前层状态。
- 禁止把旧 session 当作长期记忆。
- 禁止把 Core-v2 brain 混入 PG brain。
- 禁止把 OpenClaw workspace 当作 PG brain。
- 禁止把 Obsidian 当成第二套 PG brain。
