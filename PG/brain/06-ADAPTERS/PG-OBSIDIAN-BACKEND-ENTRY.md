# PG Obsidian 后层入口说明

## 定位

Obsidian PG 是 PG brain 的后层管理入口。

它负责：

- 查看 PG brain
- 搜索 PG brain
- 整理 PG brain
- 关联 PG brain
- 生长 PG brain
- 分拣材料
- 管理长期记忆

## 真源

Obsidian PG 使用同一个真源：

`~/SYOO1-PG/brain`

它不是另一套 brain。  
它不与 OpenClaw PG 做双脑同步。  
它只是同一个 PG brain 的可视化和后层管理入口。

## 与 OpenClaw PG 的关系

OpenClaw PG 负责：

- 前台对话
- 审核判断
- 工具调用
- 监管协作
- 执行 PG 相关任务

Obsidian PG 负责：

- 后层整理
- 记忆管理
- 可视化
- 关联网络
- 生长与复盘

二者共用一个 PG brain。

## 与旧 58789 的关系

Obsidian PG 不读取旧 58789 的：

- session
- workspace
- runtime
- token
- logs
- 前层状态

旧 58789 视作废弃旧壳。

## 与 Core-v2 的关系

Obsidian PG 只管理 PG brain。  
不得把 Core-v2 brain 混入 PG brain。

Core-v2 是执行脑 / 日常协作脑。  
PG 是监管脑 / 审核脑 / 备用判断脑。
