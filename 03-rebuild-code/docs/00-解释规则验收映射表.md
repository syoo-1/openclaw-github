# 00-解释规则验收映射表

## 定位

本表不是新规则总纲，也不是新验收题库。

本表用于把系统中的解释性规则，对应到已有验收题 / 验收卡 / Skill，防止：

1. 解释越写越多，但没有验收。
2. 验收题存在，但不知道覆盖了哪条解释。
3. 本轮局部完成被误说成全部完成。
4. 后续减重时误删仍有验收价值的解释性规则。

## 三、后续减重原则

1. 上位解释卡不直接删。
2. 已有验收覆盖的局部重复说明，可以压缩。
3. 尚无验收覆盖的解释，先补验收题，再考虑压缩。
4. 验收题不能代替上位规则，只能验证上位规则是否被正确执行。
5. 每次压缩后必须跑对应验收题。
6. 阶段收口必须写清：
   - 已完成
   - 未完成
   - 下一步
   - 不能夸大什么

## 四、当前结论

第 7 步当前不是“全面压缩解释规则”，而是先完成映射。

- 后续可按映射补固定题，再压缩局部重复解释。

当前不可说：

- 所有解释性规则都已压成验收项。
- 第 7 步已全部完成。
- 03 上位解释卡可以删除或大幅压缩。
