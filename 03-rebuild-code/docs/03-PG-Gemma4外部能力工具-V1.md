# 03-PG Gemma4 外部能力工具 V1

## 上位规则

本卡为局部说明卡，只处理 PG 调用 Gemma4 的局部规则。

涉及 Core / PG 主判、模型位、外部工具、fallback、Gemma4 / oMLX 职责边界时，统一受以下上位卡统领：

- `03-Core-PG主判与外部工具权力结构-V1.md`

若本卡与上位卡冲突，以上位卡为准。

## 一、定位

Gemma4 是 PG 可调用的外部辅助工具，不进入 PG 模型槽，不是近一，不是 PG 主脑，不拥有主判断权，不作系统裁定。

## 二、当前状态

现行口径：

- PG 调用 Gemma4 时，不再走 llama.cpp / GGUF / `pg-call-gemma4.sh` 旧链。
- Gemma4 / oMLX 统一作为外部能力工具，不进入 PG 模型槽，不替代近一 / Kimi 主判。
- 现行外部工具方向优先复用 oMLX 服务链：
  - 服务地址：`http://127.0.0.1:18000`
  - 统一入口：`~/MLX/oMLX/omlx-tool.sh`
- PG 可将输入材料整理为任务包后交给 oMLX / Gemma4 做初筛、整理、摘要、图片理解或多模态材料包生成。
- 工具结果必须回到近一 / Kimi / PG 主判链审核后再回报老林。
- Telegram 全模态入口自动路由到 oMLX / Gemma4，仍属于后续接线与验收项；未验收前不得说已经通车。

## 三、适用任务

Gemma4 只适合非主权类辅助任务：

- 文本整理
- 摘要
- 改写
- 结构化
- 要点提取
- 大白话转换
- 辅助分析

## 四、禁止任务

以下任务不得交给 Gemma4 裁定：

- 身份、关系、主权归属
- 当前阶段、当前现实、主线判断
- 达标判断、放行结论
- 系统边界裁定
- PG / Core / 02 / 03 主脑关系裁定

遇到上述任务，必须回到近一 / Kimi、PG 正式主脑链、`002-PG-03-达标扫描` 或 03 正式工艺卡。

## 五、调用流程

1. 近一先判断任务是否适合交给 Gemma4
2. 适合时调用现行 oMLX / Gemma4 外部工具链；不得回退到 llama.cpp / GGUF 旧链
3. Gemma4 只完成具体辅助任务
4. 近一审核 Gemma4 输出
5. 近一用自己的话回报老林

Gemma4 输出不得直接作为最终裁定。

## 六、当前边界

当前只确认 Gemma4 / oMLX 作为外部能力工具的定位已固化；Telegram 全模态自动路由尚未完成验收。

尚未完成：

- 自动触发
- 自动分流
- 自动路由
- 长期稳定性观察

因此不得说 Gemma4 已正式接入 PG 自动能力链。

## 七、硬结论

Gemma4 当前只是 PG 的外部辅助工具，可用于文本整理、改写、摘要、结构化等任务；不得裁定身份、关系、主线、阶段、系统边界、达标或放行问题。
