# 03-前层经历池抽取与入脑卡

## 定位

本卡是 03 工艺方法卡，用于规定壳内前层经历池如何抽取、缓冲、分流与升格。

本卡不定义 02 主权内容本身，只规定壳内材料进入 02 前的准入流程。

相关上位 / 验收入口：

- `00-前层降权固定验收题.md`
- `02-brain/00-GOVERNANCE/02-非入口目录说明.md`
- `03-rebuild-code/docs/00-规则权威入口表.md`
- `03-rebuild-code/docs/00-解释规则验收映射表.md`

---

## 一、总原则

壳内原生记忆体系一律先降为前层经历池。

凡来自以下来源的内容，进入母脑前都先视为前层材料：

- workspace
- 当前会话
- sessions
- handoff
- status / current
- `.openclaw` 运行痕迹
- dreaming / active memory
- logs 中的经历线索
- 壳内临时生成的身份、关系、阶段描述
- 壳内阶段性总结、阶段性尾巴、阶段性现场

硬规则：

壳内材料不得绕过缓冲和判断，直接写入长期正式层。

---

## 二、入脑总流程

固定流程：

壳内前层经历池
→ 08-IMPORT-STAGING
→ 分类判断
→ 分流
→ 升格 / 留存 / 延后

第一入口：

- `08-IMPORT-STAGING`

目的：

- 防止壳内内容直接越权
- 防止未整理材料污染长期层
- 防止当前热信息冲坏制度层
- 保留来源与责任边界

---

## 三、分类判断

进入 `08-IMPORT-STAGING` 后，先分为五类：

| 类别 | 特点 | 去向 |
|---|---|---|
| 原始证据类 | 需要保留原样，后续可能回看原始语境 | `05-RAW` |
| 当前主线类 | 与当前推进强相关，时效性强 | `02-MAINLINE` |
| 已可提炼类 | 已能形成较稳定中间结论 | `04-COMPILED` |
| 待观察类 | 有价值但证据不足，暂不升格 | `99-DEFERRED` |
| 长期候选类 | 接近长期原则、身份底座或稳定现实 | 先入 `04-COMPILED` 或 staging 候选位 |

---

## 四、正式分流

1. 原始证据类 → `05-RAW`
2. 当前主线类 → `02-MAINLINE`
3. 已可提炼类 → `04-COMPILED`
4. 待观察类 → `99-DEFERRED`
5. 长期候选类 → 先入 `04-COMPILED` 或 `08-IMPORT-STAGING` 中的明确候选整理位

长期候选类必须再根据正式判断决定是否升格。

---

## 五、升格规则

只有经过判断后，才允许升格。

可升入 `01-IDENTITY`：

- 身份定义
- 用户关系底座
- 稳定称谓
- 长期稳定互动口径

可升入 `03-LONGTERM`：

- 长期原则
- 长期偏好
- 稳定现实
- 长期有效的结构性结论

可升入 `00-GOVERNANCE`：

- 准入规则
- 治理边界
- 分层口径
- 工程硬约束
- 母本级施工规则

可留在 `04-COMPILED`：

- 已有提炼价值
- 但还不该升格为长期主权
- 适合作为可复用中间成果

---

## 六、禁止事项

禁止：

1. 壳内材料直接写入长期正式层。
2. 把前层印象当成后层主脑依据。
3. 把运行现场里的旧身份、旧端口、旧阶段直接恢复为当前现实。
4. 从 `07-RETIRING`、`08-IMPORT-STAGING`、`99-DEFERRED` 反向定义当前正式入口。
5. 把未验证材料升格为长期原则或治理规则。
6. 把一次性排障过程当作长期稳定方法。

---

## 七、验收标准

合格标准：

1. 壳内材料先进入 `08-IMPORT-STAGING`。
2. 每批材料有来源、分类、去向。
3. 升格前能说明判断理由。
4. 不能直接污染 `00-GOVERNANCE`、`01-IDENTITY`、`03-LONGTERM`。
5. 与当前正式入口冲突时，听当前正式入口。
6. 能通过 `00-前层降权固定验收题.md` 的相关题目。

---

## 八、一句话定义

前层经历池不是主脑；它是壳内经历进入正式母脑前的缓冲池、分流池和候选池。
