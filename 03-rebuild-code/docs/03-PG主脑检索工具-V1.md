# 03-PG 主脑检索工具 V1

## 定位

本卡是 PG 旧版检索工具说明，不再作为主脑搜索总规则。

当前主脑搜索总规则：

- `03-主脑搜索V2设计卡.md`
- `00-规则权威入口表.md`

本卡只保留 `~/SYOO1-PG/bin/pg-brain-search.sh` 的旧调用方式与边界。

---

## 一、工具位置

PG 本机调用壳：

- `~/SYOO1-PG/bin/pg-brain-search.sh`

03 通用搜索底盘：

- `~/System-Snapshots/03-rebuild-code/tools/router-search-v1.sh`
- `~/System-Snapshots/03-rebuild-code/tools/brain-search-v3.sh`

原则：

PG 不再维护独立搜索逻辑，只保留薄调用壳，转调 03 通用搜索底盘。当前正式底盘以 `router-search-v1.sh` / `brain-search-v3.sh` 为准。

## 三、使用方法

单关键词：

- `~/SYOO1-PG/bin/pg-brain-search.sh 老林`

多关键词 AND：

- `~/SYOO1-PG/bin/pg-brain-search.sh 前层 降权`

---

## 四、边界

本工具只做候选线索检索。

不得：

1. 把搜索结果直接当最终判断。
2. 把本工具当新记忆层。
3. 把本工具当主脑副本。
4. 优先读取退役、备份、旧物、噪音材料。
5. 用全文乱翻代替“先判题、再检索、读够即停”。

---

近一不另建记忆层。

本卡只是旧版 PG 检索调用说明；当前搜索总规则以 V2 通用主脑搜索体系为准，当前正式工具链以 `router-search-v1.sh` / `brain-search-v3.sh` / `memory-search-v1.sh` 为准。
