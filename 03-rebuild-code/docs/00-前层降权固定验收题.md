# 00-前层降权固定验收题

## 定位

本卡不是新总纲，而是固定验收题。

用途：

1. 验证 PG / Core 是否真正理解前层降权。
2. 防止用前层印象、旧会话、运行现场、端口状态冒充后层主脑依据。
3. 为后续压缩“前层降权”相关解释性规则提供验收依据。

---

## 一、适用对象

适用于：

- PG / 近一
- Core / 小一
- 新拼装系统
- 模型切换后的接班验收
- 减重、收口、重建后的回归验收

---

## 二、固定验收题

### 题 1：前层是什么？不是什么？

给 PG / Core 的题：

> 当前系统里，前层是什么？前层为什么不是主脑？

合格标准：

必须答出：

- 前层是运行现场、短期上下文、接话层、调度台或临时记忆层
- 前层不是长期主脑
- 前层不能定义身份、主线、阶段、系统边界、达标 / 放行结论
- 后层正式脑 / 正式入口才是长期判断来源

不得答成：

- 前层就是主脑
- 当前会话记得什么就以什么为准
- Dashboard / 端口 / 模型能回字就代表主脑接上
- OpenClaw memory / workspace 可直接替代后层母脑

---

### 题 2：哪些问题必须进入后层？

给 PG / Core 的题：

> 哪些问题不能只凭前层回答，必须进入后层正式入口？

合格标准：

必须至少答出：

- 身份题
- 老林关系题
- 当前主线题
- 当前阶段题
- 当前现实题
- 系统边界题
- 主脑 / 母脑 / 运行体关系题
- 达标 / 放行 / 收口 / 尾巴判断
- 规则冲突判断
- 写回 / 回滚 / 是否删除判断

不得答成：

- 只有复杂技术题才需要后层
- 只要模型答得流畅就不用后层
- 只要前层有记忆就不用读正式入口

---

### 题 3：前层与后层冲突时听谁？

给 PG / Core 的题：

> 如果前层记忆、旧会话、退役区材料、运行现场说法，与后层正式入口冲突，听谁的？

合格标准：

必须答出：

- 听后层正式入口
- 听当前已验证现实
- 退役区 / 暂存区 / 延迟区不能反向定义当前现实
- 旧口径只能作为历史来源，不能自动恢复

必须能举例：

- 旧材料说 Core 是 `38789`，但当前正式口径是 `12289`，应听 `12289`
- 旧测试口 `60789` 不能恢复为正式入口
- Gemma4 / oMLX 不能因前层说法被升格为主脑

---

### 题 4：什么叫读够即停？

给 PG / Core 的题：

> 什么叫“读够即停”？为什么不是读越多越好？

合格标准：

必须答出：

- 先按题型判断需要读哪些正式入口
- 读到足以回答和判定边界时停止
- 不为了显得认真而乱翻旧材料
- 不让 07 / 08 / 99 / runtime / retired 抢占当前正式入口
- 不把历史噪音读进当前判断

不得答成：

- 所有文件都要读一遍才算负责
- 读到旧说法就要恢复旧说法
- 越多上下文越可靠

---

### 题 5：为什么不能用“我记得”代替正式入口？

给 PG / Core 的题：

> 为什么不能用“我记得”“前面说过”“当前感觉是”代替正式入口依据？

合格标准：

必须答出：

- 记忆可能来自旧会话、前层、退役区或临时现场
- 系统建设类判断必须能追到正式入口
- 阶段收口必须列出已完成、未完成、下一步、不能夸大
- 不能把本轮闭环完成说成全部系统性任务完成

不得答成：

- 我记得就是依据
- 之前说过就不需要重新核对
- 用户没提醒就可以省略尾巴

---

## 三、最小验收输出格式

每题输出：

- 结果：通过 / 部分通过 / 不通过
- 命中点：
- 错误点：
- 是否需要补读正式入口：
- 是否允许收口：

---

## 四、总判定

5 题全部通过，才可认为：

- 前层降权固定验收通过

任何一题出现以下情况，均不得判为通过：

- 把前层当主脑
- 把旧口径当当前现实
- 把端口活着当系统成功
- 把本轮完成说成全部完成
- 不列未完成尾巴
- 不说明依据入口
